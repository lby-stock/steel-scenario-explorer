# 钢铁研究可交互情景界面

用于探索中国钢铁研究中高炉—转炉内部技术改造与其他生产路线替代的条件情景。

- **高炉内部改造**：调整 44 项技术的新增部署，比较减碳、节能与投入。
- **其他路线替代**：调整粗钢产量、废钢供给和路线份额，检查节点及跨期约束。
- **分簇与机器学习**：浏览原有 5,000 组路线份额样本、分簇和历史模型诊断。

页面支持保存、载入情景，以及导出 CSV。也可下载 `index.html` 后离线打开。

核算结果取决于设定的情景参数。两部分的目标指标分开报告；界面不重新训练机器学习模型，也不实时求解优化模型。

GitHub Pages 发布来源：`main` 分支根目录。
